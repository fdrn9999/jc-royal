## 미구현 / 범위 밖

- **운영 메일 발송(가입 인증, 비밀번호 재설정)**: Resend 연동 코드와 한/영 브랜드 템플릿(`apps/api/src/lib/mail.ts`)은 있다. Resend에서 인증한 발신 도메인이 없어 `MAIL_FROM`을 비워 두었다. 그동안 운영 가입은 이메일 인증 없이 진행되고, 비밀번호 재설정은 관리자가 링크를 발급한다(`docs/DEPLOYMENT.md` 2절).
- **개인정보 처리방침·이용약관 확정**: `/privacy`·`/terms` 페이지(한/영)와 가입 화면 링크는 있지만 **법무 검토 전 초안**이다(화면에 초안·"검토 필요" 표시). 보관 기한, 보호책임자, 국외 이전 고지, 약관 동의 방식, 등급·연령 등 검토 필요 항목은 `docs/PRIVACY_OPERATIONS.md` 9절. 이 상태로 `main`에 병합하면 운영에 그대로 배포된다.
- **봇 플레이어**: 없음. 설계안을 제시했고 오너 결정 대기.
- **프로필 이미지 업로드**: 이미지 파일 업로드(R2)는 없다. https URL만 지원.
- **핸드 히스토리 리플레이 애니메이션**: 단계별 재생은 없다. 텍스트·카드 타임라인만 지원.
- **토너먼트**, 리더보드, 업적: 없음.
- **부하·성능 테스트**: 로컬 `wrangler dev`에서만 수행했다(`pnpm test:load`, `docs/LOAD_TEST.md`). 최대 30테이블·소켓 300개, 10테이블 연속 30핸드까지 오류 0, 칩 보존 일치. Cloudflare 엣지·운영 환경 부하 테스트는 하지 않았다. 지속 실행의 꼬리 지연(최대 1.2초) 원인은 확인하지 않았다.
- **아카데미 칩 보상**: 지급하지 않는다(배지만). 필요해지면 서버 원장 트랜잭션·1회 한정·멱등성 키로 구현해야 한다.
- **영어 학습 문구**: 1차 자체 검토만 했고 원어민 감수는 받지 않았다.
- **실기기 검증**: iOS Safari·Android Chrome 실기기에서 확인하지 않았다. 터치 정렬, 핀치 차단, 바텀시트는 브라우저 자동화(Chrome 모바일 에뮬레이션)로만 검증했다.

## 알려진 문제와 제약

1. **poker-engine-ts 0.1.3 결함 보정**: 어댑터 보정 3건과 패치 1건(`docs/ENGINE_NOTES.md`). 엔진을 업그레이드할 때 재검증이 필요하다.
2. **무료 플랜 CPU 10ms**: PBKDF2 10만 회 해싱이 무료 플랜에서 CPU 한도를 넘을 수 있다. 운영은 Workers Paid를 권장한다.
3. **로컬 `wrangler dev`의 닫힌 소켓**: 서버가 닫은 소켓이 클라이언트에서 CLOSING 상태로 남는다. 서버 동작은 정상이다.
4. **레이트 리밋 카운터의 D1 쓰기**: 테이블 WebSocket 연결 1회마다 `rate_limits`에 1행을 쓴다(부하 시나리오에서 연결 수와 같음). 트래픽이 많아지면 D1 쓰기 한도에 영향을 준다. 이때는 Workers Rate Limiting 바인딩으로 바꾸는 것을 검토한다.
5. **로비 실시간 현황**: DO가 상태가 바뀔 때 D1에 기록한다. 로비는 5초 폴링이라 최대 수 초 지연된다. 숨긴 탭에서는 부르지 않지만, 화면에 띄워 둔 로비 1개당 시간당 최대 720회 요청한다(`docs/DEPLOYMENT.md` 5절). 즐겨찾기·최근 방문은 기기(브라우저)별로 저장되어 다른 기기와 동기화되지 않는다.
6. **쇼다운 공개 정책**: 쇼다운 참여자 카드는 모두 공개한다. 패배 핸드 자동 머크는 엔진이 지원하지만 사용자 설정 UI는 연결하지 않았다.
7. **개발 환경 표시 차이**: 테이블 화면 웹폰트(Pretendard, Cinzel)는 외부 CDN에서 불러온다. 오프라인이면 시스템 글꼴로 대체된다.
8. **앱 핑**: 웹 클라이언트가 테이블 소켓마다 25초에 한 번 `ping`을 보내 DO가 응답한다. DO 요청과 실행 시간에 잡히므로 `setWebSocketAutoResponse` 전환을 권고한다(미적용, `docs/DEPLOYMENT.md` 5절).
