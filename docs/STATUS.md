## 미구현 / 범위 밖

- **비밀번호 재설정 메일 발송**: 메일 서비스 미연동. 개발 환경은 화면에 링크 표시, 운영은 관리자가 링크를 발급한다. Resend 연동은 오너 확인 대기.
- **봇 플레이어**: 없음. 설계안을 제시했고 오너 결정 대기.
- **프로필 이미지 업로드**: 이미지 파일 업로드(R2)는 없다. https URL만 지원.
- **핸드 히스토리 리플레이 애니메이션**: 단계별 재생은 없다. 텍스트·카드 타임라인만 지원.
- **토너먼트**, 리더보드, 업적: 없음.
- **부하·성능 테스트**: 수행하지 않음.
- **아카데미 후속 과제**(우선순위 순): 학습 진도 서버 저장(D1 `academy_progress`, 현재는 계정별 localStorage), 오답 기반 복습, 엔진 판정 랜덤 퀴즈, 규칙 기반 연습 봇과 자유 연습 테이블, 첫 실전 핸드 코칭, 입문 테이블 태그, 핸드 기록 → 관련 레슨 링크, 배지·업적(칩 보상은 원장 트랜잭션·1회 한정·멱등성 필수), 익명 이탈·오답률 지표, 영어 번역 감수.
- **실기기 검증**: iOS Safari·Android Chrome 실기기에서 확인하지 않았다. 터치 정렬, 핀치 차단, 바텀시트는 브라우저 자동화(Chrome 모바일 에뮬레이션)로만 검증했다.

## 알려진 문제와 제약

1. **poker-engine-ts 0.1.3 결함 보정**: 어댑터 보정 3건과 패치 1건(`docs/ENGINE_NOTES.md`). 엔진을 업그레이드할 때 재검증이 필요하다.
2. **무료 플랜 CPU 10ms**: PBKDF2 10만 회 해싱이 무료 플랜에서 CPU 한도를 넘을 수 있다. 운영은 Workers Paid를 권장한다.
3. **로컬 `wrangler dev`의 닫힌 소켓**: 서버가 닫은 소켓이 클라이언트에서 CLOSING 상태로 남는다. 서버 동작은 정상이다.
4. **레이트 리밋 카운터의 D1 쓰기**: 트래픽이 많아지면 D1 쓰기 한도에 영향을 준다. 이때는 Workers Rate Limiting 바인딩으로 바꾸는 것을 검토한다.
5. **로비 실시간 현황**: DO가 상태가 바뀔 때 D1에 기록한다. 로비는 5초 폴링이라 최대 수 초 지연된다.
6. **쇼다운 공개 정책**: 쇼다운 참여자 카드는 모두 공개한다. 패배 핸드 자동 머크는 엔진이 지원하지만 사용자 설정 UI는 연결하지 않았다.
7. **개발 환경 표시 차이**: 테이블 화면 웹폰트(Pretendard, Cinzel)는 외부 CDN에서 불러온다. 오프라인이면 시스템 글꼴로 대체된다.
